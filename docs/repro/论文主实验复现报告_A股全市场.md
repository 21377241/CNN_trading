## 1. 实验设定

| 项 | 本复现 | 论文 |
|----|--------|------|
| 宇宙 | A 股全市场复权（~4990 只，剔除 ST） | CRSP 美股 |
| 价格 / 市值 | 复权 OHLC；VW 用流通市值 | CRSP 复权收益构价 / 市值 |
| IS（样本内训练） | **2000–2007**（70% train / 30% val，随机划分） | 约前 8 年（美股 1993–2000） |
| OOS（样本外） | **2008–2025**（模型固定，不滚动重训） | 其后全程 OOS |
| 主设定 | **I20/R20** 月频；**I5/R5** 周频；**I20/R5** 周频（论文最优规格） | Table II / Table I / 主文最优 |
| 集成 / 超参 | 5 ensembles；lr=1e-5；batch=128；dropout=0.5；早停 patience=2 | 同 |
| CNN | I20: 64→128→256（FC=46080，~70.9 万参）；I5: 64→128（FC=15360，~15.5 万参）；Xavier | 附录一致 |

| 组合 | 按 `up_prob` 十分位；H-L = D10 − D1；另报 Top5/10/20 | 主表为十分位 |

## 6. 稳健性：剔涨停 + 市值宇宙 TopK

设定（脚本 `ashare_train/5_analyze_ashare_topk_robust.py`）：

1. **涨停不可买**：信号日（`ending_date`）用复权收盘价还原未 clip 日收益；若 ≥ 该股当日涨停幅度 − 0.5pct，则剔除。主板 10%；创业板 2020-08-24 后 / 科创板 20%；北交所 2023-09-04 后 30%。  
2. **市值宇宙**：每期按流通市值取最大 500 / 1000 / 2000 / 3000 只（及全市场），再在可买集合内按 `up_prob` 选 Top5/10/20。  
3. 涨停占比：I20 约 **1.50%**（9377/626841）；I5 约 **1.55%**（41906/2699831）；I20R5 约 **1.48%**（39669/2687822）。明细与分宇宙报告在 `WORK_SPACE/ashare_model_res_*/topN_robust/`。

## 7. 综合解读

| 问题 | 结论 |
|------|------|
| 流水线 / 模型是否对齐？ | 是（容量、超参、IS/OOS 设定对齐论文） |
| 哪组主设定有效？ | **I20/R5** 与 **I5/R5** 均强；I20/R20 仅弱正 |
| 最可信指标？ | 十分位单调性 + **H-L Sharpe**（I20R5 EW ≈ **2.65**，I5 EW ≈ 2.39） |
| 论文最优规格是否成立？ | **是**——I20/R5 在 A 股 EW/VW H-L 均为三组最高或并列最高 |
| 实盘含义？ | I5 周频 TopK 剔涨停后失效；**I20R5 TopK 剔涨停后几乎不变**（全市场 Top20 EW Sharpe 0.58）。主结果仍看十分位 H-L |

**一句话**：方法对齐后 **I20/R5 等权 H-L Sharpe 2.65 为本项目最强主结果**，验证论文最优规格；I5/R5 次之（EW 2.39）；I20/R20 月频仅弱正。I5 周频 Top5 不可交易；I20R5 TopN 剔涨停后仍为正。
