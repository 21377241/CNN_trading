> 本文件是在 E7 结果产生前冻结的分析方案，称为 frozen analysis protocol，不称为 pre-registration：它没有在第三方平台登记，而且作者已经看过 E1–E6 的单变量结果。

## 1. 研究问题与假设

**问题**：仅用 20 日 OHLCV 训练的 chart-CNN 与 1D-CNN 信号，在控制同一窗口内的传统价量特征和窗口外的标准公司特征之后，是否仍然包含对下周收益的预测信息？两者的增量信息是否彼此不同？

| 假设 | 内容 | 主检验 |
|---|---|---|
| H1 | 每个规范模型信号在 A+B 层控制下仍能预测下周收益 | 第 5 节规格 M1(k)，系数 β_k |
| H2 | chart-CNN 与 1D-CNN 同时放入时各自保留增量信息（Distinct Signals） | 规格 M2，β_chart 与 β_1d 各自显著 |
| H3 | 增量信息不是由某一个传统特征的条件分布驱动的 | 第 6.3 节条件双重排序 |

## 2. 规范模型与样本

- **模型**：`model_registry.md` 中三个 canonical 模型。

| 代号 | registry 名 | 文件 | sha1（前 16 位） |
|---|---|---|---|
| chart | `chartcnn_e1b_ric` | `WORK_SPACE/paper/E2_matched_is_ind_chrono_ric/preds/pred_cnn_oos.csv` | `be0a89e6b16f522c` |
| 1d | `onedcnn_120` | `WORK_SPACE/paper/E2C_temporal_1dcnn_120/preds/pred_1dcnn120_oos.csv` | `6f1982cad36565e9` |
| mlp4 | `mlp4_120_s5` | `WORK_SPACE/paper/E2F_mlp_depth/preds/pred_mlp4_oos.csv` | `4bf2a2214272f312` |

- 读取时核对 sha1，必须与 `registry.csv` 一致；不一致即停止运行。
- **期间**：2008-01-04 至 2025-12-31，922 个周度信号日。
- **基础样本**：三个模型预测键的交集，共 2,687,822 个股票-周。
- **主样本**：基础样本中满足以下条件的观测：
  - 主因变量可计算（第 3 节）；
  - A 层和 B 层控制变量全部不缺失。
- 报告每一步的样本损失（行数、周数、股票数）。
- 预期主要损失来自 12-1 动量（要求至少 250 个交易日历史）。
- **全样本对照**：B 层缺失值按当周截面中位数填补，并加缺失指示变量。只作稳健性检验。
- **独立样本（2026Q1）**：约 14 周，周数不足以做 FM 推断。只报告 M2 规格的逐周系数均值和 Rank IC 描述统计，不做显著性判断。

## 3. 因变量

所有收益用**未裁剪**的后复权价格计算（后复权已包含分红再投资）。设 t 为信号日，T 为下一个信号日。

| 代号 | 定义 | 角色 |
|---|---|---|
| `ret_oo` | `Open_{t+1}` 到 `Open_{T+1}` 的收益，即 t+1 开盘进入，下一个信号日之后的首个开盘退出 | **主因变量**（与 E9 主执行口径一致） |
| `ret_cc` | `Close_t` 到 `Close_T` 的收益，即未裁剪的历史标签口径 | 对照 |
| `ret_val` | 原裁剪标签 | 仅用于与 E1–E6 衔接，不作推断依据 |

**无法交易时的处理**（与 E9 共用，在 `build_returns.py` 中一次实现）：

- **进场日停牌**：t+1 没有交易，则 `ret_oo` 缺失，计入“不可进场”，报告比例。
- **进场日一字涨停**：t+1 开盘价等于涨停价且全天价格不变时，视为无法买入，`ret_oo` 缺失。只在 E7 的稳健性检验中剔除；E9 中作为执行约束处理。
- **退出日停牌**：顺延到复牌后的首个开盘价，最多顺延 4 周。超过 4 周仍未复牌的，用最后一个收盘价计算，并标记。
- **持有期内退市**：用最后交易日收盘价计算，退市收益设为 0。稳健性检验中设为 −50%（参照 A 股退市股票的常见损失）。
- `ret_cc` 采用同样的顺延和退市规则。因此原标签缺失的那 0.72% 样本（见 `E0_data_timing.md` 第 5 节）在 `ret_cc` 和 `ret_oo` 中都被纳入。

因变量在主规格中**不做 winsorize**。稳健性检验中逐周截面 winsorize 到 1% 和 99%。

## 4. 控制变量

所有变量只使用截至信号日 t 收盘的信息，并用未裁剪的日收益计算。

### 4.1 A 层：与模型输入同窗口的传统特征（20 个交易日）

| 变量 | 定义 |
|---|---|
| `rev_1w` | 最近 5 个交易日的累计收益 |
| `ret_20d` | 最近 20 个交易日的累计收益 |
| `max_20d` | 20 日内的最大日收益（MAX，Bali–Cakici–Whitelaw） |
| `vol_20d` | 20 日日收益的标准差 |
| `vtrend` | log（近 5 日平均成交量 / 近 20 日平均成交量） |
| `range_20d` | 20 日内 (High−Low)/Close 的均值 |
| `clv_20d` | (Close_t − 20 日最低价) / (20 日最高价 − 20 日最低价) |
| `ma_gap` | Close_t / MA20 − 1（图像输入包含均线） |

**目的**：检验模型是否只是在重新发现窗口内的常见技术指标。如果 A 层就能消除 β，结论是模型信号可以被这些指标解释。

### 4.2 B 层：窗口外信息与公司特征

数据来自 `build_extended_panel.py` 从原始 CSV 抽取的字段（见 `E0_data_timing.md` 第 2.2 节）。

| 变量 | 定义 | 备注 |
|---|---|---|
| `mom_12_1` | 从 t−250 到 t−20 个交易日的累计收益 | 要求至少 250 个交易日历史 |
| `size` | log(流通市值_t) | |
| `turn_20d` | 20 日平均换手率（`换手率` 字段） | 基于流通股本的真实换手率；模型输入中没有股本信息 |
| `illiq_20d` | log(1 + 20 日均值 \|r_d\| / 成交额 × 1e8) | Amihud 非流动性 |
| `ivol_20d` | 20 日日收益对当日全市场流通市值加权收益回归的残差标准差 | 要求至少 15 个有效日 |
| `bm` | 1/市净率，市净率 ≤ 0 时设为缺失 | 由数据商计算，时点性质无法验证 |
| `ep` | 1/滚动市盈率，保留负值 | 同上 |
| 行业 FE | `所属行业` 虚拟变量，逐周在行业内去均值 | 当前分类，需要披露 |

### 4.3 变量变换

- 每周截面上，把每个控制变量和每个模型得分转换为秩，并线性映射到 [−0.5, 0.5]。
- 系数含义：其他变量不变时，从截面最低值到最高值对应的周收益差。不同变量的系数可以直接比较。
- 稳健性检验：先逐周 winsorize 到 1% 和 99%，再截面 z-score。
- 加入行业 FE 时，对因变量和全部自变量都做逐周行业内去均值。

## 5. 回归规格

每周做截面 OLS，然后对时间序列取 Fama–MacBeth 均值。

| 规格 | 自变量 | 用途 |
|---|---|---|
| M0-A | A 层 | 控制变量基准 |
| M0-AB | A + B + 行业 FE | 完整控制基准 |
| S(k) | 只有 score_k | 无控制时的单变量系数 |
| MA(k) | A + score_k | 只控制同窗口特征 |
| **M1(k)** | **A + B + 行业 FE + score_k** | **H1 主检验**，k ∈ {chart, 1d, mlp4} |
| **M2** | **A + B + 行业 FE + score_chart + score_1d** | **H2 主检验，也是全文核心规格** |
| M3 | M2 + score_mlp4 | 三个模型同时放入 |

**主结论只依据 M1(k) 和 M2。** 其余规格只用来展示系数如何随控制变量的加入而变化。

## 6. 推断与输出

### 6.1 Fama–MacBeth

- 系数为周度截面系数的均值。
- 标准误用 Newey–West，lag = 4（`experiments/common/metrics.py` 中的 `newey_west_t`，与 `E3_shared_specific/utils.py` 的实现逐位一致）。
- 报告 t 值、95% 置信区间、观测数、周数和平均调整 R²。
- **增量 R²**：每周计算 R²(M1(k)) − R²(M0-AB)，报告均值及其 NW t。M2 相对于 M1(chart) 和 M1(1d) 同样计算。
- **经济量级**：β × 52 即为年化收益差。
- 同时报告标准化系数：每周按截面标准差缩放后的系数。

### 6.2 残差 Rank IC

- 每周把 score_k 对 A + B + 行业 FE 做截面回归，取残差 e_k，计算 Spearman(e_k, ret_oo)。
- 报告周度均值、NW t，以及正 IC 周数的比例。
- **残差相关**：每周计算 Spearman(e_chart, e_1d) 的均值，量化两个信号控制之后各自独有的部分。

### 6.3 条件双重排序（H3）

- 条件变量：`rev_1w`、`ret_20d`、`max_20d`、`vol_20d`、`turn_20d`、`size`、`illiq_20d`。
- 做法：
  1. 每周按条件变量分成 5 组；
  2. 组内再按 score_k 分成 10 组；
  3. 计算 EW 的 H-L（第 10 组减第 1 组）收益，并在 5 个条件组之间取平均；
  4. 同时报告每个条件组内的 H-L。
- 推断：NW t（lag 4），Sharpe 按 √52 年化（见 `docs/protocol/sharpe_convention.md`）。

### 6.4 输出文件

写入 `WORK_SPACE/paper/E7_incremental/`：

- `fm_coefs.csv`：规格、变量、系数、t、95% 置信区间、N、周数；
- `fm_r2.csv`；
- `resid_ric.csv`；
- `double_sort.csv`；
- `sample_flow.csv`；
- `subperiod_*.csv`；
- 每次运行的 `run_manifest.json`：记录 git hash、输入文件 sha1 和运行时间。

## 7. 判定规则（冻结）

由于检验次数较多，主阈值采用 |t| ≥ 3.0（Harvey–Liu–Zhu 2016）。同时报告 |t| ≥ 1.96 下的结论。

| 结果 | 判定 | 论文表述 |
|---|---|---|
| M1(k)：β_k 的 t ≥ 3，且残差 Rank IC 的 t ≥ 3 | H1 成立 | “score_k 在 A+B 层控制下仍包含增量预测信息” |
| M1(k)：β_k 显著，但残差 Rank IC 不显著（或反之） | H1 部分成立 | 两者都报告，不作强表述 |
| MA(k) 显著，但 M1(k) 不显著 | 信号可被窗口外特征解释 | “score_k 的预测力主要与 B 层中的特征重合”，指明是哪个变量（逐一加入 B 层变量进行分解） |
| M2：β_chart 与 β_1d 的 t 都 ≥ 3 | H2 成立 | 保留 “Same Information, Distinct Signals” |
| M2：只有 β_1d 显著 | H2 不成立 | 改写为 “chart-CNN 的信息被 1D-CNN 包含”。这是事先确定的备选叙事，不追加规格去挽救 |
| M2：只有 β_chart 显著 | H2 不成立（反向） | 对称改写 |
| 双重排序：至少 5/7 个条件变量下平均 H-L 的 t ≥ 3 | H3 成立 | “增量信息不是由单一传统特征的条件分布驱动的” |

**H1 的方向要求**：β > 0。若显著为负，视为不成立并单独讨论。

## 8. 稳健性检验（全部事先列出，结果全部报告）

1. 因变量换成 `ret_cc`，以及原 `ret_val`。
2. 因变量逐周 winsorize 到 1% 和 99%。
3. 变量变换改为 winsorize 加 z-score。
4. 去掉估值变量（bm、ep）；去掉行业 FE。
5. 分样本：2008–2013、2014–2019、2020–2025。
6. 股票池：
   - 剔除每周流通市值最小的 30%（壳价值问题，Liu–Stambaugh–Yuan 2019）；
   - 剔除上市不满 1 年的股票；
   - 剔除信号日收盘涨停或跌停的股票；
   - 剔除进场日一字涨停的股票。
7. 退市收益设为 −50%。
8. 全样本：B 层用中位数填补并加缺失指示变量。
9. WLS：截面回归以流通市值为权重。

## 9. 条件执行：非线性控制基准

**触发条件**：H1 至少对一个模型成立。

**做法**：
- 用 A+B 层控制变量（不含模型得分）训练 HistGB，预测 `ret_cc`。
- 训练、验证划分与规范模型相同：训练集 2000–2005，验证集 2006–2007，边界处设 1 周 embargo。
- 超参数网格：`max_depth ∈ {3, 5}`、`learning_rate ∈ {0.05, 0.1}`、`max_iter ≤ 500` 并启用 early stopping。
- 按验证集 Rank IC 选择超参数。
- 生成 OOS 得分 `ctrl_gbm`，以秩变换的形式加入 M1(k) 和 M2，构成 M1G(k) 和 M2G。

**用途**：检验模型信号是否只是控制变量的非线性组合。M1G/M2G 只作为稳健性证据，不改变第 7 节的判定，但必须报告。

## 10. 表述边界

- **可以写**：
  - “incremental predictive information beyond standard price, liquidity, and firm characteristics”
  - “not subsumed by”
  - “distinct”
- **E8 之前不写**：“alpha”“risk-adjusted”“anomaly”“priced factor”。
- **不写**：“causal”“the CNN sees patterns humans cannot”，以及 “pre-registered”。
- 预测力不等于可交易收益。可交易性由 E9 回答。
- 行业为当前分类，PE/PB 时点无法验证，这些局限必须写入正文的局限性部分。

## 13. 局限

- 行业分类是当前分类，不是历史时点数据。
- PE/PB 由数据商计算，无法验证是否严格按公告时点更新。
- 没有财务报表明细，无法构建盈利或投资类控制变量（如 ROE、资产增长）。
- 没有分析师和机构持仓数据。
- ST 在行级别剔除后，摘帽首日的收益跨越整个 ST 期间（`E0_data_timing.md` 第 5 节）。
- 规范模型在训练、验证边界处各有 1 周标签重叠（只影响模型选择，量级为 2.1% 的样本），现有模型不重训。
