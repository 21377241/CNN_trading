## 1. 研究问题与假设

**问题**：只用 20 个市场交易日的 OHLCV 训练的 chart-CNN 与 1D-CNN 信号，在控制同一窗口内的传统价量特征和窗口外的标准公司特征之后，是否仍然包含对下周收益的预测信息？两者的增量信息是否彼此不同？

| 假设 | 内容 | 主检验 |
|---|---|---|
| H1 | 每个规范模型信号在 A+B 层控制下仍能预测下周收益 | 第 5 节规格 M1(k)，系数 β_k |
| H2 | chart-CNN 与 1D-CNN 同时放入时各自保留增量信息（Distinct Signals） | 规格 M2，β_chart 与 β_1d 各自显著 |
| H3 | 增量信息不是由某一个传统特征的条件分布驱动的 | 第 6.3 节条件双重排序 |

## 2. 规范模型与样本

- **模型**：registry v2 中的三个规范模型，全部在干净数据上训练（`clean_spec.md` 第 5 节），5 个成员集成：

| 代号 | registry v2 名 | 输入 | 训练规格 |
|---|---|---|---|
| chart | `chartcnn_clean` | I20R5 图像（Jiang 画法） | 干净数据上按原网格重新搜参，选中组合 5 模型集成 |
| 1d | `onedcnn_140` | 140 维（20 天 × 7） | `config_1dcnn_140.yaml`，seed 42–46 |
| mlp4 | `mlp4_140` | 140 维 | (128, 64, 32, 16)，seed 42–46 |

- 预测文件及其 sha1 在 registry v2 中登记后才能运行 E7；读取时核对 sha1，不一致即停止。
- **期间**：2008-01-04 至 2025-12-31，922 个周度信号日。
- **基础样本**：`universe_weekly.feather` 中 `split == 'oos'` 的全部股票-周（信号日有交易、非 ST、上市历史至少 39 个市场交易日）。干净版本的 OOS 预测不按标签过滤，因此三个模型的预测键与基础样本完全相同（不再取交集）。v1 中“信号日可交易、下周末不交易”而没有得分的 0.72% 样本，在 v2 中有得分，直接进入样本。
- **主样本**：基础样本中满足以下条件的观测：
  - 主因变量可计算（第 3 节）；
  - A 层和 B 层控制变量全部不缺失。
- 报告每一步的样本损失（行数、周数、股票数），以及按板块（主板、创业板、科创板、北交所）的构成。
- 预期主要损失来自 12-1 动量（要求至少 250 个市场交易日的上市历史）。
- **全样本对照**：B 层缺失值按当周截面中位数填补，并加缺失指示变量。只作稳健性检验。
- **独立样本（2026Q1）**：约 14 周，只报告 M2 的逐周系数均值和 Rank IC 描述统计，不做显著性判断。

## 3. 因变量

所有收益用未裁剪的后复权价格计算。设 t 为信号日，T 为下一个信号日。

| 代号 | 定义 | 角色 |
|---|---|---|
| `ret_oo` | `Open_{t+1}` 到 `Open_{T+1}`：t+1 开盘进入，下一个信号日之后的首个开盘退出 | **主因变量**（与 E9 主执行口径一致） |
| `ret_cc` | `Close_t` 到 `Close_T`，按下面的顺延和退市规则补齐 | 对照 |
| `ret_label` | `Close_t` 到 `Close_T`，T 日无交易则缺失（即训练标签） | 对照，用于与模型训练目标衔接 |

日收益在每只股票内部由收盘价逐日计算，不使用原始 CSV 的 `前收盘价` 和均线字段。

**无法交易时的处理**（与 E9 共用，在 `build_returns.py` 中一次实现）：

- **进场日停牌**：t+1 没有交易，则 `ret_oo` 缺失，计入“不可进场”，报告比例。
- **进场日一字涨停**：t+1 开盘价等于涨停价且全天价格不变。主规格保留并标记 `entry_lock_up`；只在第 8 节第 6 项的稳健性检验中剔除；E9 中作为执行约束处理。
- **退出日停牌**：顺延到复牌后的首个开盘价，最多顺延 4 周。超过 4 周仍未复牌的，用最后一个收盘价计算，并标记。
- **持有期内退市**：用最后交易日收盘价计算，退市收益设为 0。稳健性检验中设为 −50%。
- `ret_cc` 采用同样的顺延和退市规则。
- 涨跌停幅度按 `clean_spec.md` 第 9 节第 6 项（D13）：ST 5%（2025-07-07 起主板 ST 10%），创业板改革后与科创板 20%，北交所 30%，新股无涨跌幅限制期不判。

因变量在主规格中不做 winsorize。稳健性检验中逐周截面 winsorize 到 1% 和 99%。

## 4. 控制变量

所有变量只使用截至信号日 t 收盘的信息，用未裁剪的日收益和送转复权后的成交量（`Vol_adj`）计算。

### 4.1 A 层：与模型输入完全相同的窗口

**窗口**：信号日 t 往前的最近 20 个**市场**交易日 W = {t−19, …, t}，与图像和 140 维特征逐日相同（`clean_window.gather_windows`）。窗口内股票无交易的日子称为缺失日；V(W) 为有交易的日子。价格路径 P 与 140 维特征的占位规则相同：缺失日取前一个有效收盘价，窗口开头的缺失日取窗口内第一个有效收盘价。窗口内的日收益 r 只在有交易日上定义，等于窗口内相邻两个有效收盘价之比减 1（跨越缺失日的收益计入复牌日，与图像中价格在空白列之后的跳变一致；窗口内第一个有交易日没有收益，满窗口共 19 个收益）。

| 变量 | 定义 |
|---|---|
| `rev_1w` | P_t / P_{t−5} − 1（最近 5 个市场交易日） |
| `ret_20d` | P_t / P_{t−19} − 1（窗口首日到 t） |
| `max_20d` | 窗口内日收益 r 的最大值（MAX，Bali–Cakici–Whitelaw） |
| `vol_20d` | 窗口内日收益 r 的标准差（ddof = 1），至少 5 个收益 |
| `vtrend` | log（最近 5 个市场交易日中有交易日的平均 `Vol_adj` / 窗口内有交易日的平均 `Vol_adj`） |
| `range_20d` | 有交易日 (High − Low) / Close 的均值 |
| `clv_20d` | (Close_t − 窗口内最低价) / (窗口内最高价 − 窗口内最低价)，最高最低只取有交易日 |
| `ma_gap` | Close_t / MA20_t − 1，MA20 为模型输入使用的完整 20 日均线（20 个有效收盘价，含回溯） |

**目的**：检验模型是否只是在重新发现窗口内的常见技术指标。A 层与模型输入用同一窗口、同一缺失日处理，使“与模型输入同窗口”的前提严格成立。

### 4.2 B 层：窗口外信息与公司特征

| 变量 | 定义 | 备注 |
|---|---|---|
| `mom_12_1` | 市场日 t−250 到 t−20 的累计收益（各取该日或之前最近的有效收盘价） | 要求上市历史至少 250 个市场交易日 |
| `size` | log(流通市值_t) | |
| `turn_20d` | 窗口 W 内有交易日的平均换手率（`换手率` 字段） | 模型输入中没有股本信息 |
| `illiq_20d` | log(1 + W 内有交易日 \|r_d\| / 成交额 的均值 × 1e8) | Amihud；至少 15 个收益 |
| `ivol_20d` | W 内日收益对同一跨度的全市场流通市值加权收益（按日复利到与该股票收益相同的区间；权重为前一日流通市值）回归的残差标准差 | 至少 15 个收益 |
| `bm` | 1/市净率，市净率 ≤ 0 时设为缺失 | 数据商计算，时点性质无法验证 |
| `ep` | 1/滚动市盈率，保留负值 | 同上 |
| 行业 FE | `所属行业` 虚拟变量，逐周在行业内去均值 | 当前分类，需要披露 |

市场收益为当日有交易股票的前一日流通市值加权日收益。

### 4.3 变量变换

- 每周截面上，把每个控制变量和每个模型得分转换为秩，并线性映射到 [−0.5, 0.5]。
- 系数含义：其他变量不变时，从截面最低值到最高值对应的周收益差。
- 稳健性检验：先逐周 winsorize 到 1% 和 99%，再截面 z-score。
- 加入行业 FE 时，对因变量和全部自变量都做逐周行业内去均值。

## 5. 回归规格

每周做截面 OLS，然后对时间序列取 Fama–MacBeth 均值。

| 规格 | 自变量 | 用途 |
|---|---|---|
| M0-A | A 层 | 控制变量基准 |
| M0-AB | A + B + 行业 FE | 完整控制基准 |
| S(k) | 只有 score_k | 无控制时的单变量系数 |
| MA(k) | A + score_k | 只控制同窗口特征 |
| **M1(k)** | **A + B + 行业 FE + score_k** | **H1 主检验**，k ∈ {chart, 1d, mlp4} |
| **M2** | **A + B + 行业 FE + score_chart + score_1d** | **H2 主检验，全文核心规格** |
| M3 | M2 + score_mlp4 | 三个模型同时放入 |

**主结论只依据 M1(k) 和 M2。** 其余规格只用来展示系数如何随控制变量的加入而变化。

## 6. 推断与输出

### 6.1 Fama–MacBeth

- 系数为周度截面系数的均值；Newey–West 标准误，lag = 4（`experiments/common/metrics.py` 的 `newey_west_t`）。
- 报告 t 值、95% 置信区间、观测数、周数和平均调整 R²。
- **增量 R²**：每周计算 R²(M1(k)) − R²(M0-AB)，报告均值及其 NW t；M2 相对于 M1(chart) 和 M1(1d) 同样计算。
- **（追加，v1 看到结果后补充）** 同时报告调整 R² 的增量及其 NW t、改善周数占比。周内 R² 增量在机制上必然非负，原指标的 t 值没有信息量。只是补充报告项，不改变第 7 节的判定。
- **经济量级**：β × 52 即为年化收益差。
- **标准化系数**：β_w × sd_w(x) 的周度均值，即自变量变动一个截面标准差对应的周收益。

### 6.2 残差 Rank IC

- 每周把 score_k 对 A + B + 行业 FE 做截面回归，取残差 e_k，计算 Spearman(e_k, ret_oo)。
- 报告周度均值、NW t、正 IC 周数的比例。
- **残差相关**：每周 Spearman(e_chart, e_1d) 的均值。

### 6.3 条件双重排序（H3）

- 条件变量：`rev_1w`、`ret_20d`、`max_20d`、`vol_20d`、`turn_20d`、`size`、`illiq_20d`。
- 每周按条件变量分 5 组，组内按 score_k 分 10 组；EW 的 H-L（第 10 组减第 1 组）在 5 个条件组之间取平均，并报告每个条件组内的 H-L。
- 推断：NW t（lag 4），Sharpe = 周均值 × √52 ÷ 周标准差（ddof = 1）。

### 6.4 输出文件

写入 `WORK_SPACE/paper/E7_incremental_v2/`：`fm_coefs.csv`、`fm_r2.csv`、`resid_ric.csv`、`double_sort.csv`、`sample_flow.csv`、`subperiod_*.csv`，以及记录 git hash、输入文件 sha1 和运行时间的 `run_manifest.json`。

## 7. 判定规则（冻结，与 v1 相同）

主阈值 |t| ≥ 3.0（Harvey–Liu–Zhu 2016），同时报告 |t| ≥ 1.96 下的结论。

| 结果 | 判定 | 论文表述 |
|---|---|---|
| M1(k)：β_k 的 t ≥ 3，且残差 Rank IC 的 t ≥ 3 | H1 成立 | “score_k 在 A+B 层控制下仍包含增量预测信息” |
| M1(k)：β_k 显著，但残差 Rank IC 不显著（或反之） | H1 部分成立 | 两者都报告，不作强表述 |
| MA(k) 显著，但 M1(k) 不显著 | 信号可被窗口外特征解释 | 指明是哪个 B 层变量（逐一加入进行分解） |
| M2：β_chart 与 β_1d 的 t 都 ≥ 3 | H2 成立 | 保留 “Same Information, Distinct Signals” |
| M2：只有 β_1d 显著 | H2 不成立 | “chart-CNN 的信息被 1D-CNN 包含”。事先确定的备选叙事，不追加规格去挽救 |
| M2：只有 β_chart 显著 | H2 不成立（反向） | 对称改写 |
| 双重排序：至少 5/7 个条件变量下平均 H-L 的 t ≥ 3 | H3 成立 | “增量信息不是由单一传统特征的条件分布驱动的” |

**方向要求**：β > 0。显著为负视为不成立，单独讨论。

**与 v1 的关系**：v2 的判定独立于 v1。论文以 v2 为主结果；v1 作为“旧数据与旧渲染器下的结果”在附录中报告并说明差异来源（`clean_cnn_impact.md`）。

## 8. 稳健性检验（全部事先列出，结果全部报告）

1. 因变量换成 `ret_cc` 和 `ret_label`。
2. 因变量逐周 winsorize 到 1% 和 99%。
3. 变量变换改为 winsorize 加 z-score。
4. 去掉估值变量（bm、ep）；去掉行业 FE。
5. 分样本：2008–2013、2014–2019、2020–2025。
6. 股票池：
   - 剔除每周流通市值最小的 30%（Liu–Stambaugh–Yuan 2019）；
   - 剔除上市不满 1 年的股票；
   - 剔除信号日收盘涨停或跌停的股票；
   - 剔除进场日一字涨停的股票；
   - **（v2 新增，数据修正带来）** 剔除窗口有效天数少于 15 天的样本（`n_obs_in_win < 15`）；
   - **（v2 新增）** 只保留 20 天全部有交易的窗口（`n_obs_in_win == 20`，Bøjstrup 式）；
   - **（v2 新增）** 剔除窗口内含 ST 交易日的样本（干净面板保留 ST 行，窗口可以包含 ST 日）。
7. 退市收益设为 −50%。
8. 全样本：B 层用中位数填补并加缺失指示变量。
9. WLS：截面回归以流通市值为权重。
10. **（v2 新增）** 板块：只用主板；2020 年起剔除创业板和科创板（训练期没有 20% 涨跌幅板块，这部分是分布外外推）。

## 9. 条件执行：非线性控制基准

**触发条件**：H1 至少对一个模型成立。

- 用 A+B 层控制变量（逐周秩变换，不含模型得分）训练 HistGB，目标为逐周 1%/99% winsorize 后的 `ret_cc`。
- 训练、验证划分与规范模型相同：训练集 2000–2005，验证集 2006–2007，边界处 1 周 embargo（与 universe 的 `embargo` 标记一致）。
- 网格：`max_depth ∈ {3, 5}`、`learning_rate ∈ {0.05, 0.1}`、`max_iter ≤ 500` 并启用 early stopping；按验证集 Rank IC 选择。
- 生成 OOS 得分 `ctrl_gbm`，以秩变换加入 M1(k) 和 M2，构成 M1G(k) 和 M2G。只作稳健性证据，不改变第 7 节的判定，但必须报告。

## 10. 表述边界

- 可以写：“incremental predictive information beyond standard price, liquidity, and firm characteristics”“not subsumed by”“distinct”。
- E8 之前不写：“alpha”“risk-adjusted”“anomaly”“priced factor”。
- 不写：“causal”“the CNN sees patterns humans cannot”“pre-registered”。
- 预测力不等于可交易收益，可交易性由 E9 回答。
- 行业为当前分类，PE/PB 时点无法验证；原始数据中科创板和北交所的覆盖以 `clean_data_reconciliation.md` 为准，这些局限写入正文。

## 11. v1 → v2 的改动

| 改动 | 理由 |
|---|---|
| 规范模型换成干净数据上的 `chartcnn_clean`、`onedcnn_140`、`mlp4_140` | 旧图像没有开盘价和收盘价，旧数据裁剪日收益、成交量未送转复权等（`clean_spec.md` 第 2 节） |
| 基础样本由 universe 直接给出，不再取三个模型预测键的交集；0.72% 无标签样本有得分并进入样本 | 干净版本的 OOS 预测不按标签过滤 |
| A 层改用与模型输入完全相同的 20 个市场交易日窗口及缺失日规则；`ma_gap` 用完整 MA20 | v1 按股票自身行数滚动，窗口与模型输入不一致（停牌时会向前多取） |
| B 层的 20 日变量同样用市场日窗口；`mom_12_1` 按市场日定位 | 与 A 层一致 |
| 因变量去掉 `ret_val`（裁剪标签），增加 `ret_label` | 干净版本不再有裁剪标签 |
| 涨跌停按 D13 规则 | v1 的规则缺 ST 5% 和新股无限制期 |
| v1 偏离日志中不涉及结果的实现细节写入正文：日收益由收盘价计算（第 3 节）、进场日一字涨停只在稳健性检验中剔除（第 3 节）、标准化系数和 HistGB 的特征与目标（第 6.1、9 节）、Newey–West 函数路径（第 6.1 节） | 这些在 v1 中是看到结果前确定的实现细节 |
| 稳健性第 6 项新增三条、第 10 项新增 | 数据修正引入了缺失日和 ST 日窗口，以及训练期外的板块 |
| 第 9 节 embargo 与 universe 一致 | 干净版本在边界处已设 embargo |
| v1 第 13 节“训练、验证边界各重叠 1 周、现有模型不重训”删除 | 干净版本已设 embargo |

## 14. 追加：ChartCNN-S 容量稳健性检验（v1 看到 E7 结果后追加）

**性质**：v1 中在 H2 结果公布之后、S 检验运行之前写定（tag `protocol-e7-s-addendum`）。v2 原样保留，论文中必须标为追加的稳健性检验。

**模型**：ChartCNN-S，E2G 中按参数量公式机械选定的 4-8-16 架构（8,306 参数），其余设定与 `chartcnn_clean` 相同。在干净图像上重新训练：超参数按 E2G 的预设网格、以验证集 Rank IC（loss 最优 checkpoint，`clean_spec.md` 第 5.1 节）选定，5 个 seed 集成。预测文件和 sha1 登记到 registry v2，记为 `s_chartS`。ChartCNN-M 只留在 E2G 容量附录。

**样本**：E7 v2 主样本中 `s_chartS` 非缺失的部分；报告覆盖率。

**规格**：与第 5 节相同的变换、行业去均值和 NW lag 4：S(s_chartS)、MA(s_chartS)、M1(s_chartS)、M2-S（A+B + `s_chartS` + `s_1d`），同时报告同一样本上的 M1(s_1d)。

**检验范围**：主规格；第 8 节全部稳健性检验，以及以 `ctrl_gbm` 为额外控制的变体；第 6.2 节残差 Rank IC；第 6.3 节双重排序（附录）；`diag_e2c_bridge` 的同一分解（探索性）。

**判定**（阈值沿用第 7 节）：

| 结果 | 判定 | 论文表述 |
|---|---|---|
| M1(s_chartS)：β 的 t ≥ 3 且残差 Rank IC 的 t ≥ 3 | H1-S 成立 | 与完整 chart-CNN 一并报告 |
| M2-S：β_chartS 的 t < 1.96，β_1d 的 t ≥ 3 | 包含结论对容量稳健 | “chart-CNN 的信息被 1D-CNN 包含，小型图像 CNN 同样如此” |
| M2-S：1.96 ≤ β_chartS 的 t < 3 | 弱证据 | “小型图像 CNN 可能保留少量增量，未达到多重检验阈值” |
| M2-S：β_chartS 的 t ≥ 3 | 结论对架构敏感 | 主结论改为限定表述；E10 中“1D + S”与“1D + 完整 CNN”并列为主结果 |

本节只在第 7 节 H2 不成立（只有 β_1d 显著）时作为容量稳健性检验运行；若 H2 成立，本节仍运行并报告，但不改变任何判定。无论方向，S 的主规格和稳健性汇总都写进正文。E3T–E5T 的机制实验不对 S 重跑。
