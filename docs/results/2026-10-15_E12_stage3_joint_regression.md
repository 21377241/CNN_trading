# E12 第三阶段：当前分数 + 一周前分数的联合预测回归

日期：2026-10-15　脚本：`experiments/E12_signal_stability/run_e12_stage3.py`　输出：`WORK_SPACE/paper/E12_signal_stability/stage3/`
代码基线：commit `7f2d000`（标签 `accepted-e11-e12s2-20261015`，E11 第一阶段与 E12 第一、二阶段验收版本）。

只使用已冻结的预测文件。没有重新训练模型，没有更新组合，也没有做新的参数搜索。第一、二阶段的输出目录未被改动。

## 1. 结论

- **主回归**：控制当前分数后，Chart-CNN 和 MLP 一周前分数的系数显著为正（β1 = 0.0129，NW t = 5.74；β1 = 0.0145，NW t = 5.82），1D-CNN 的约等于零（β1 = 0.0016，t = 0.63）。模型间配对比较确认差异真实存在：1D 与 Chart 的 β1 差为 −0.0114（t = −5.60），1D 与 MLP 的差为 −0.0129（t = −5.55），两者的 bootstrap 置信区间都不含 0。Chart 与 MLP 之间没有差异（t = 0.81）。
- **控制之后两个模型分化**：加入 E7 的 15 个传统特征、行业去均值和另外两个模型的当期分数后：
  - MLP 的旧分数仍然显著（0.0057，t = 4.93），且两个时期的 t 都在 3 以上；
  - Chart 的旧分数降到 0.0030（t = 2.73，低于项目的 3 门槛），在 2014–2026 只剩 t = 1.69。Chart 旧分数中的大部分信息，是其他模型当期分数和传统价格特征也包含的共同信息。
- **时期**：Chart 主回归的 β1 几乎全部来自 2014–2026（2008–2013 只有 t = 0.99）。Chart 与 MLP 的 β1 在所有规格和时期都为正，没有方向反转。1D 在加入控制后出现前正后负，但两段都没有达到 |t| ≥ 3。
- **量级**：用全样本的 FM 均值组合当前分数与旧分数，IC 大约只提高 4%（Chart 从 0.0476 到 0.0493，MLP 从 0.0494 到 0.0516）。这是样本内权重的近似值，统计上显著，但量级小。

## 2. 设计

- **样本**：沿用 E12 第二阶段的共同样本，即在 t、t−1、t−2、t−4 都有分数且有标签 `ret_val` 的股票-周，共 955 周、2,930,594 行（2008-02-01 至 2026-09-24）。
- **回归**：每个模型、每周做一次截面 OLS：
  \[ Z(\operatorname{Rank} R_{i,t+1}) = a_t + \beta_{0,t} Z(S_{i,t}) + \beta_{1,t} Z(S_{i,t-1}) + \varepsilon_{i,t} \]
  - \(Z\) 表示在当周回归样本内取截面平均秩后标准化；收益同样处理。
  - `ret_val` 是从信号周收盘到下一个信号周收盘的收益，与第二阶段的 IC 标签相同。
- **恒等式**：两个回归变量都标准化时，每周有 \(\beta_{1,t} = (IC_{1,t} - \rho_t IC_{0,t})/(1-\rho_t^2)\)，其中 \(\rho_t\) 是当前分数与旧分数的秩相关。因此 β1 就是第二阶段 \(D_m\) 的回归版本。逐周核对时，两边最大绝对差 ≤ 1.5e−15。
- **统计量**：FM 均值、NW t（lag 4）、移动区块 bootstrap 95% 置信区间（8 周为一个区块，2000 次重复，种子 20261015）。β1 的模型间比较使用逐周配对差，统计方法相同。
- **规格**：按顺序报告，主回归优先：

| 规格 | 回归变量 | 样本 |
|---|---|---|
| base（主回归） | S_t、S_{t−1} | 共同样本，955 周 |
| others | base + 另外两个模型的当期分数 | 同上 |
| base_e7 | S_t、S_{t−1} | E7 主样本（控制变量完整，`in_main`），954 周、2,745,114 行 |
| ctrl | base_e7 + E7 Layer A/B 共 15 个特征，y 和 X 都做行业去均值（与 E7 主 FM 相同） | 同上 |
| ctrl_others | ctrl + 另外两个模型的当期分数 | 同上 |

base_e7 用于分离样本变化的影响。它与 base 几乎相同（Chart 的 β1 为 0.0128 对 0.0129，MLP 为 0.0141 对 0.0145），所以 ctrl 规格中 β1 的下降来自控制变量本身，而不是样本变了。

补充观察（只作描述，不作推断）：

- **"others" 规格中当期分数的系数**：Chart 当期分数的系数从 0.0469 降到 0.0101，MLP 从 0.0489 降到 0.0222，1D 只从 0.0689 降到 0.0525。Chart 的当期信息大部分也被 1D、MLP 的当期分数包含。在 ctrl_others 中，Chart 当期分数与旧分数的系数接近（0.0027 对 0.0030），两者都很小。
- **2008–2013 加入控制后 β1 反而上升**：Chart 从 0.0045 升到 0.0078，1D 从 −0.0037 升到 0.0041。说明这一时期旧分数的原始预测力被某些传统特征或行业成分抵消了，具体是哪一项，本阶段没有拆分。

## 6. 对照预设的结果解读表

| 预设结果 | 是否出现 | 说明 |
|---|---|---|
| Chart/MLP 旧分数显著，1D 不显著 | 主回归中出现 | 配对比较确认 1D 与 Chart、MLP 的 β1 差异显著，不是"一个显著、一个不显著"带来的错觉 |
| 三模型旧分数均不显著 | 未出现 | — |
| Chart/MLP 旧分数显著，但控制传统特征和其他模型后消失 | 只对 Chart 大体成立 | Chart 降到 t = 2.73，在 2014–2026 不显著；MLP 没有消失 |
| 结果在两个时期方向不同 | Chart/MLP 未出现 | Chart/MLP 的 β1 在全部规格和时期都为正；1D 在控制规格下有符号变化，但没有达到 \|t\| ≥ 3 |

因此可以写进论文的、较稳健的表述只有一条：**MLP 的当前分数没有完全涵盖它上一周预测中的收益信息，并且这部分信息不是传统价格特征或其他模型当期分数所能解释的**。Chart 也有同样的现象，但它的"旧信息"多数是共同信息，在近期样本中控制后不再显著。

## 7. 不能由此得出的结论

- β1 > 0 不说明 Chart/MLP 的新分数变化是"噪声"。β0 在所有规格下都远大于 β1，新分数本身仍然包含主要的预测信息。
- β1 > 0 不说明保留旧持仓或平滑分数一定更赚钱。IC 的提高只有约 4%，而且使用的是全样本、样本内的 FM 权重。是否有经济价值，需要把预测更新带来的边际收益和调仓的边际成本放在一起比较，这不在本阶段范围内。
- 第一阶段的"排名持续性"差异和本阶段的 β1 都是在窗口与市场状态混合下的平均值，不能直接归因于模型结构。
- E7 的控制变量来自同一段价格历史；行业去均值只出现在 ctrl 和 ctrl_others 两个规格中。
