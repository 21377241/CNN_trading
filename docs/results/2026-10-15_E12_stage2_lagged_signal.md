# E12 第二阶段：滞后预测信号的有效性

写于 2026-10-15。不训练模型、不改组合、不重跑 E9。脚本 `experiments/E12_signal_stability/run_e12_stage2.py`（约 40 秒），输出 `WORK_SPACE/paper/E12_signal_stability/stage2/`。

## 0. 结论摘要

1. **三个模型的预测信息都衰减得很快，而且前两周的衰减速度基本相同。** 分数过时一周后，IC 只剩当期的约三分之一：Chart 34%、1D 37%、MLP 35%。过时两周后剩 28%、30%、23%。模型之间这两个比例的差异，95% 置信区间都包含 0。按你事先给出的判读规则，**"预测信息有效期限不同"不能作为解释换手差异的核心机制**。
2. **只有在 4 周时出现有限的差异。** 1D 保留 17% [10%, 23%]，Chart 保留 10% [1%, 20%]，MLP 保留 4%（不显著）。1D 与 Chart 比值之差的置信区间只是勉强不含 0；1D 与 MLP 的差别更明确。
3. **排名持续性与信息衰减是脱钩的。** 1D 的相邻周排名相关是 0.38，Chart 和 MLP 只有 0.07 和 0.05，差五倍以上；但三者一周后保留的 IC 比例几乎一样。
   - 如果旧分数只能通过"与当期分数相关"来预测收益，Chart 一周前分数的 IC 应约为 0.074 × 0.048 ≈ 0.004，实际却是 0.016，约为前者的 4.7 倍；MLP 约为 7 倍。
   - 1D 的实际滞后 IC（0.026）与这个推算值（0.027）几乎相同。
   - 也就是说，Chart 和 MLP 每周的大幅重排并没有带走预测信息：被"换掉"的旧排名仍然能预测下一周的收益。
4. **1D 在每个年龄上的 IC 都更高。** 1D − Chart 的差在 k=0/1/2/4 时分别为 0.023、0.010、0.008、0.007（t 均 ≥ 3.9）。1D 的优势在于整条衰减曲线的水平更高，而不是衰减得更慢。
5. **分时期**：2008–2013 年 Chart 衰减更快（一周后只剩 9%，1D 为 23%）；2014–2026 年三者在一、二周上几乎重合（49% / 45% / 46%）。早期样本中 Chart 衰减更快的现象，在后期不成立。

对 E12 两阶段的合并判断：**1D 换手低，主要不是因为它预测的信息持续得更久**。三个模型的信息都是短期的。差别在于 Chart 和 MLP 的分数每周有很大一部分在变动，而这部分变动并不对应信息的过期。

## 1. 口径

| 项 | 设定 |
|---|---|
| 指标 | IC<sub>m</sub>(k) = Spearman<sub>i</sub>(S<sup>m</sup><sub>i,t−k</sub>, R<sub>i,t+1</sub>)，k ∈ {0, 1, 2, 4}，事先固定 |
| 得分 | E7 v2 冻结得分；滞后分数直接取 t−k 周当时实际生成的预测，跨训练窗口时不用新模型回填 |
| 收益 | E7 的未来周收益标签 `ret_val`（t 日收盘至下一信号周收盘），与主分析 Rank IC 相同。E9 执行收益不参与 |
| 共同样本 | (i, t) 需同时具有 S<sub>t</sub>、S<sub>t−1</sub>、S<sub>t−2</sub>、S<sub>t−4</sub> 和 `ret_val`。四个年龄、三个模型都用同一组股票-周：955 周（2008-02-01 至 2026-09-24）、2,930,594 行，平均每周 3,069 只，占这些周有标签样本的 97.3% |
| 统计 | 逐周 Rank IC 的均值、NW t（滞后 4 周）、95% CI；IC(0) − IC(k) 的逐周配对差；模型间同年龄的 IC 差，以及衰减幅度之差 |
| 衰减比例 | IC(k)/IC(0)，用移动区块 bootstrap 求 95% CI（区块 8 周，2,000 次，种子固定）；模型间比例差使用同一组重抽样周 |
| 持续性推算 | ρ<sub>k</sub> × IC(0)，ρ<sub>k</sub> 为同一样本中 S<sub>t−k</sub> 与 S<sub>t</sub> 的排名相关。含义：旧分数若只通过与当期分数的相关来预测收益，其 IC 大约是多少。这是高斯线性结构下的近似，只用于描述 |
| 时期 | 按 t 所在年份划分 2008–2013 与 2014–2026 |

**样本一致性核对**：全样本 IC(0) 为 0.0484 / 0.0715 / 0.0492，与主表完全相同。共同样本上为 0.0476 / 0.0708 / 0.0494，差异不超过 0.001。

注：这里沿用主分析的 959 周标签，不是 E9 的 958 个组合周，因为 `ret_val` 在最后一个信号周仍然可用。

## 3. 排名持续性与信息衰减的对照

| 模型 | 相邻周排名相关 ρ<sub>1</sub> | 推算 IC(1) = ρ<sub>1</sub> × IC(0) | 实际 IC(1) | 实际 / 推算 | ρ<sub>2</sub> | 推算 IC(2) | 实际 IC(2) |
|---|---:|---:|---:|---:|---:|---:|---:|
| Chart-CNN | 0.074 | 0.0035 | 0.0163 | 4.7 倍 | 0.020 | 0.0010 | 0.0133 |
| 1D-CNN | 0.383 | 0.0272 | 0.0263 | 0.97 倍 | 0.205 | 0.0145 | 0.0210 |
| MLP | 0.051 | 0.0025 | 0.0174 | 7.0 倍 | −0.007 | −0.0003 | 0.0111 |

- **1D**：一周前分数的预测力，和它与当期分数的相关所能解释的几乎一致，没有多余的信息。
- **Chart 和 MLP**：一周前、两周前的分数与当期分数几乎不相关，却仍能预测下一周的收益。也就是说，当期分数没有保留旧分数中仍然有效的那部分信息。

这一现象目前有两种同样可能的解释，本阶段无法区分：

| 解释 | 含义 |
|---|---|
| 估计噪声 | 背后存在较持续的可预测成分，但 Chart 和 MLP 每周对它的估计噪声很大，相邻两周的估计彼此相关很低，但各自都含有有效信息 |
| 一系列不同的短期信号 | 模型每周捕捉的是不同、各自短命但仍有数周余效的信号（类似上周收益：自身几乎不持续，但多周反转效应依然存在） |

两种解释对换手的含义不同。前者意味着 Chart 和 MLP 的大部分换手是在为估计噪声付费；后者意味着这些换手是在追逐真实但短暂的信号。

- 2008–2013 年 Chart 一周后的 IC 不显著，衰减最快：1D − Chart 比例差为 +14 pp [+4, +26]。

- 因此"Chart 衰减更快"只是早期样本中的现象，不能作为全样本结论。

## 5. 对研究主线的含义

你设定的判读规则是：如果三个模型的滞后 IC 衰减基本相同，就不能把"预测信息有效期限不同"作为核心机制，而应回头检查网络输出为什么变化如此大。本结果符合这一情形：

| 环节 | 现在的证据 |
|---|---|
| 预测排名持续性不同 | **成立**（E12 第一阶段）：0.38 对 0.07 / 0.05 |
| 预测信息有效期限不同 | **基本不成立**：一、二周的衰减比例相同；只有 4 周时 1D 略多保留，且后期 MLP 归零 |
| 换手需求不同 | 不能用信息有效期来解释。Chart 和 MLP 的分数每周有很大一部分在变动，而这部分变动并不对应信息过期 |
| 经济价值不同 | E11：64% 来自毛收益。而本阶段显示，1D 的整条 IC 曲线都更高 |

更准确的表述是：1D 的经济优势来自两点。第一，它在每个信号年龄上的预测力都更强；第二，它的分数不包含大量随周变化、却不对应信息过期的成分。后一点是换手低的直接原因，但它的性质（估计噪声，还是一系列短期信号）还需要检验。

## 6. 可选的下一步（本阶段不执行）

1. **偏 IC 检验**：在每周截面上，控制当期分数之后，检验旧分数对下一周收益的增量预测力。这能直接检验第 3 节的推算，不需要高斯近似。
2. **分数与已知短期特征的关联**：Chart 和 MLP 的分数是否主要随上周收益等快速变化的特征波动。这可以区分"估计噪声"与"一系列短期信号"。
3. **网络输出敏感性（含图像缩放）**：三个模型输入相同，比较它们对相邻周输入变化的敏感程度。MLP 同样不持续，说明问题不只在于图像栅格化。

以上都只用冻结分数与 t 时刻已知的特征，不需要训练模型。
