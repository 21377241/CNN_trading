## Track 总览

**背景**：E2/E2B 已表明同信息集下 CNN、MLP、HistGB 相关中等、可互补。E3 进一步问：**共识信号有多强？各模独有残差是否可交易？这些差异对应什么价格路径结构？结构依赖性能否用扰动/删列验证？**

**逻辑链**（由浅入深）：


| 步骤   | 问什么                        | 证据类型                   |
| ---- | -------------------------- | ---------------------- |
| E3-0 | Shared / Specific **有多强**？ | 预测力（IC / Sharpe）       |
| E3-1 | 模型**极端分歧**时，OHLC 结构差什么？    | 条件均值差 + NW t           |
| E3-2 | Specific 与哪类**显式特征块**相关？   | 截面 block R²            |
| E3-3 | CNN-spec **依赖**哪些图像结构？     | 扰动后 specific Sharpe 变化 |
| E3-4 | Tabular-spec **依赖**哪些特征列？  | 删列重训后 specific Sharpe  |
| E3-5 | 如何写成**金融翻译表**？             | 叙事汇总（非新实验）             |


**固定协议**：Fair Chrono；MLP = chrono Rank-IC early-stop + bag k=10；E3-0/1/2 复用三模 preds **不重训**；E3-4 冻结 chrono_ric 超参仅改特征列（MLP ablation 同步 bag k=10）；E3-3 用 E1b-ric `checkpoint{0..4}` + 在线 `DrawOHLC`；对齐键 `(StockID, ending_date)`。

## 评测指标与读表说明（本 Track）


| 指标                     | 含义                                           | 怎么读                                       |
| ---------------------- | -------------------------------------------- | ----------------------------------------- |
| **Rank IC**            | 每日截面 Spearman(分数, `ret_val`) 再跨日平均           | 大于 0 且 NW t 大 → 排序有预测力                    |
| **NW t**（lag=4）        | 对日序列均值做 Newey–West HAC t                     | 看 **绝对值**：abs(t)>1.96 ≈ 5% 显著；符号只表方向      |
| **EW / VW H-L Sharpe** | 十分位多空、等权/市值加权、`ann_factor=52`                | 经济幅度；本面板 EW 通常强于 VW                       |
| **截面 z-score**         | 当日 `(S − mean) / std`（pandas `std`，ddof=1）   | **仅用于构造 Shared**；Specific 回归用原始 `up_prob` |
| **三元残差**               | 每日 OLS：一模 ~ 另外两模（带截距）的残差                     | = 控他模后线性解释不掉的部分                           |
| **ΔX**                 | 见下方公式                                        | 大于 0：A 看多且 B 看空的一侧，特征更大                   |
| **drop%**              | `(baseline − ablated) / abs(baseline) × 100` | **正=变差**；≥20% 为 Phase 2 预注册成功线            |
| **block R²**           | 每日 cs_zscore(Y)~block 特征的 OLS R²，再跨日平均       | 比**相对排序**，不宣称绝对解释充分                       |


分歧统计量：

$$
\Delta X_t = \overline{X}*{t,A^{+}B^{-}} - \overline{X}*{t,A^{-}B^{+}}
$$

通用定义见 glossary §2–3、§6。

## E3-0 — Shared / Specific

### 设计


| 项            | 设定                                                                 |
| ------------ | ------------------------------------------------------------------ |
| **问题**       | 三模共识有多强？控住另外两模后，各模是否仍有可交易残差？                                       |
| **输入**       | `pred_cnn/mlp/histgb_oos.csv` 的 `up_prob` → S_C, S_M, S_H          |
| **Shared**   | 每日对各分数做截面 z-score，再平均（公式见下）                                        |
| **Specific** | 每日用**原始**概率做三元 OLS 残差（公式见下）；当日 n≥50                                |
| **评价**       | 对 Shared / Specific / raw 做截面 `rank(pct=True)` → Rank IC + 十分位 H-L |
| **与 E2B B5** | B5 是两两残差；此处是**三元**残差，数字不可直接等同                                      |
| **解读基准**     | Shared 与至少一个 Specific：IC 与 EW Sharpe 均大于 0（预注册 P1-1）               |


Shared：

$$
S^{sh} = \frac{z(S_C)+z(S_M)+z(S_H)}{3}
$$

CNN-specific（MLP / HistGB 同理，控另外两模）：

$$
S_C = \alpha + \gamma_M S_M + \gamma_H S_H + u_C,\qquad S_C^{sp} := u_C
$$

### 结论分析

- **Shared 仍最强共识组合**（IC 0.042、Sharpe 3.72），略高于 bagged MLP raw。
- **MLP raw 升至最强单模**（0.041 / 3.70）；CNN / HistGB raw 不变。
- **MLP-spec 显著且最强**（Sharpe 2.57）；CNN-spec 仍显著（1.14）。
- **HistGB-spec 大幅削弱**（IC NW t=1.50、p≈0.13；Sharpe 0.51）：强 MLP 吸收了大量原属 HGB 的线性可解释部分——三元残差下 HGB 独有 alpha 不再稳健。
- Specific 弱于对应 raw：符合拆掉与他模重叠；关键是 CNN/MLP 残差仍可交易。
- EW 远大于 VW：alpha 更多落在等权/中小盘空间。

**本步能下 / 不能下**：能确立“强 Shared + CNN/MLP Specific”；**HGB-spec 在 bagged-MLP 面板上不再作为主证据**。结构解释 → E3-1/2；依赖 → E3-3/4。

## E3-1 — Disagreement（80/20）

### 设计


| 项        | 设定                                                                             |
| -------- | ------------------------------------------------------------------------------ |
| **问题**   | 两模型极端意见相反时，两边股票的价格路径特征差多少？                                                     |
| **集合**   | A⁺B⁻：rk(S_A)>0.8 且 rk(S_B)<0.2；反向同理                                            |
| **统计量**  | 上式 ΔX_t（集合内等权）；两侧 n≥5 才计入该日                                                    |
| **推断**   | 跨日均值(ΔX) + NW t（lag=4）；abs(t)>1.96 视为显著                                        |
| **特征**   | Recent / Geometry / Volume / Volatility / Gap / Size / Limit（公式见设计文 §4.3；无换手率） |
| **三对**   | CNN–HGB、CNN–MLP、MLP–HGB                                                        |
| **解读基准** | 至少一对在 Recent/Geometry/Volume 上 abs(NW t)>1.96（P1-2）                            |
| **边界**   | ΔX 是**条件均值差**，不是“该特征导致了分歧”                                                     |


集合定义：

$$
A^{+}B^{-}:\ \mathrm{rk}(S_A)>0.8\ \text{且}\ \mathrm{rk}(S_B)<0.2
$$

$$
A^{-}B^{+}:\ \mathrm{rk}(S_A)<0.2\ \text{且}\ \mathrm{rk}(S_B)>0.8
$$

### 结果（完整，`e31_delta_summary.csv`）

Δ>0：第一模型极端看多、第二模型极端看空的一侧，特征均值更大。 表示 abs(NW t)>1.96。

### 三对对照（总括）

- **CNN–HGB**：动量 + 波动 + 市值；相对放量不显著。
- **CNN–MLP**：近端动量 + 量能 + 市值（bag 后更接近 vs HGB；下影退居次要）。
- **MLP–HGB**：波动 + 量 + 振幅（表内也互补）。
- 三对 `body_ratio` 均非主因。
- 成功标准 P1-2 **通过**。

**本步能下 / 不能下**：能给“吵架长什么样”的可命名画像；**不能**做结构因果（→ E3-3/4），也不能把 Δ 直接写成“CNN 喜欢下影所以赚”。

## E3-2 — Spec × Feature-block R²

### 设计


| 项         | 设定                                                                                  |
| --------- | ----------------------------------------------------------------------------------- |
| **问题**    | Shared / 各 Specific 与哪一类显式价格结构块更相关？                                                 |

## E3-3 — CNN image perturbation

### 设计


| 项       | 设定                                                       |
| ------- | -------------------------------------------------------- |
| **问题**  | CNN-specific 通道依赖图像上的哪些结构？破坏后 specific Sharpe 是否下降？      |
| **权重**  | E1b-ric `ric-full-p5`，`checkpoint{0..4}`，`up_prob` 五模型平均 |
| **流程**  | 180 维窗内 OHLC/V → 预注册扰动 → `DrawOHLC`（60×64，含 MA20+量柱）→ 前向 |
| **再残差** | 见下方公式；S_M、S_H **保持未扰动**                                  |
| **扰动**  | `mask_last5`；`flatten_wick`；`shuffle_days`；`zero_volume` |
| **覆盖**  | OOS 2008–2025 全年份（按年断点续跑）                                |
| **成功线** | 至少一种扰动使 CNN-spec Sharpe 相对基准降 ≥20%                       |


$$
S_{C,sp}^{mask} = S_C^{mask} - \widehat{\mathbb{E}}[S_C^{mask} \mid S_M, S_H]
$$

## E3-5 — Explicit financial translation

### 设计

非新实验：把 E3-0…4 固化为一张对照表 + 叙事；**不引入**新 feature block。制度机制（T+1 / 真涨跌停字段）**后置**。

### 翻译表


| 观察              | 结构含义                                | 证据                               |
| --------------- | ----------------------------------- | -------------------------------- |
| Shared 最强       | 三模共识 ≈ 短中期动量 + 量能共识                 | E3-0 Sharpe 3.72；E3-2 Recent/Volume |
| MLP raw 最强单模    | 稳定化后表格浅网可超过 CNN/HistGB              | E2 / E3-0 S_mlp 0.041 / 3.70     |
| MLP-spec 主导独有 alpha | 控 CNN+HGB 后残差 Sharpe 2.57          | E3-0                             |
| HGB-spec 削弱     | 强 MLP 吸收原 HGB 线性重叠；三元残差不再稳健         | E3-0 NW p≈0.13                   |
| CNN vs HGB 吵架   | 动量 + 低波 + 大盘                        | E3-1（与刷新前同向）                     |
| CNN vs MLP 吵架   | 近端动量 + 量能（相对/绝对）为主                  | E3-1 r_1/r_5/v_end               |
| CNN-spec 依赖     | **近 5 日 K 线** 近乎充分必要                | E3-3 mask_last5                  |
| Tabular-spec 依赖 | **近 5 日列** 近乎充分必要；MLP 另对 HL/volume 敏感 | E3-4                             |


### 总述（可进讨论段）

> 同一 20 日 OHLCV 上，稳定化后的 MLP 成为最强单模，但三模仍共享以近期收益为主的强共识（Shared）；CNN 与 MLP 保留显著 specific，HistGB-spec 在强 MLP 下被大幅吸收。极端分歧主要落在动量、波动、市值与量能。扰动与删列表明：独有 alpha 的共同命门仍是**近端路径**。
