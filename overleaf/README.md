# Overleaf Paper Draft

This directory is designed to be uploaded directly to an empty Overleaf project.

## Files

- `main.tex`: entry point.
- `sections/`: paper sections.
- `tables/`: LaTeX tables with current key numbers.
- `figures/`: placeholder directory for exported figures.
- `references.bib`: starter bibliography.

## Upload to Overleaf

Zip the contents of this directory, upload the zip to the empty Overleaf project, and set `main.tex` as the main document if Overleaf does not detect it automatically.

## Next edits

The current draft is intentionally a clean, compilable skeleton. Before submission, fill missing table entries, add exported figures, and adapt the format to the target journal or conference template.
